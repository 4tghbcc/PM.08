# PM.08# Cloud Kitchen — Панель администратора

Веб-приложение для управления тёмным кухонным цехом (Cloud Kitchen).
Разработано в рамках производственной практики ПМ.08 «Разработка дизайна веб-приложений»
(Университет «Синергия», специальность 09.02.07).

## Демо

🔗 **Живая версия:** https://ВАШ_ЛОГИН.github.io/cloud-kitchen/

**Демо-доступ:**
- Логин: `admin`
- Пароль: `admin123`

## Возможности

- **Авторизация** — вход с запоминанием пользователя, сообщения об ошибках.
- **Регистрация** — валидация логина, пароля, ФИО, телефона, e-mail, согласие на обработку ПД.
- **Учёт продаж и отчётность** — фильтры по периоду и блюду, статистика по заказам,
  выручке, себестоимости и прибыли, таблица заказов.
- **Справочники** — блюда, ингредиенты, сотрудники (CRUD через модальные окна).
- **Тарифы и скидки** — управление скидками (процент / фиксированная сумма, вкл/выкл).

## Технологии

- HTML5, CSS3, JavaScript (ES6+)
- Хранение данных: `localStorage` (имитация БД)
- Адаптивная вёрстка, тёмная тема с акцентным жёлтым цветом
